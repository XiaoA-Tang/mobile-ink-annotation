# 色板与粗细面板 GoodNotes 风格重设计

日期：2026-08-13
范围：mobile-ink-annotation 插件（原生覆盖层的 OverlayToolbar 弹出面板）

## 目标

将颜色选择面板和粗细选择面板从现有「朴素框 + 两阶选色 + 原生 slider」改为 GoodNotes 风格的视觉与交互，同时修复粗细滑块水平拖动与 Obsidian 侧边栏手势冲突的问题。并补全悬浮栏按钮的选中/按下视觉反馈。

## 现状

- **颜色面板**：7 主色 + 5 色阶的两阶选择；点色阶后立即关闭面板，改错色需重开；自定义颜色行有冗余「应用」按钮；整体视觉朴素（方形 cell + 浅色边框）。
- **粗细面板**：原生 `<input type="range">` 无自定义样式；4 个方形预设按钮（2/3/5/8）；水平拖动无手势隔离，会与 Obsidian 侧边栏滑动冲突。
- **工具栏按钮**：原生覆盖层（`.mobile-ink-native-overlay`）下缺少 `:hover`、`.mobile-ink-active`、`:active` 等状态样式，工具选中不可见，按下无反馈，触感麻木。

## 设计

### 1. 颜色面板（GoodNotes 风格）

**布局（从顶到底）：**
- 标题行：「颜色」文字（左侧，加粗）
- 色点网格：6 列 × 3 行 = 18 色，圆形色点（aspect-ratio 1:1，border-radius 50%）
- 底部分隔线 + 取色器按钮（居中偏左，圆形彩色圆环，GoodNotes 风）—— 点击打开系统原生颜色选择器

**交互：**
- 点击色点 → 立即应用颜色，面板保持打开（不自动关闭），选中色点有白圈 + 外圈高光（GoodNotes 风格）
- 点击外部或再次点颜色按钮 → 关闭面板
- 取色器点击 → 打开系统原生颜色选择器

**颜色列表（18 色），每行 6 色：**

| 行 | 色 1 | 色 2 | 色 3 | 色 4 | 色 5 | 色 6 |
|---|---|---|---|---|---|---|
| 1（中性） | `#111111` 黑 | `#333333` 深灰 | `#666666` 中灰 | `#999999` 浅灰 | `#cccccc` 银灰 | `#ffffff` 白 |
| 2（暖色） | `#e53935` 红 | `#ff7043` 橙 | `#ffb300` 黄 | `#fdd835` 亮黄 | `#43a047` 绿 | `#00acc1` 青 |
| 3（冷+其他） | `#1e88e5` 蓝 | `#3949ab` 深蓝 | `#8e24aa` 紫 | `#ec407a` 粉 | `#6d4c41` 棕 | `#d7ccc8` 浅棕 |

选中态：2px 白色描边 + 外圈 2px 半透明白色光晕（box-shadow），色点内有白色✓勾号（细体，当前选中色有对比时可见；浅色/白色用深色勾号）。

**取色器：**
- 30px 圆形按钮，彩虹色锥形渐变背景 + 内圈 2px 边框（GoodNotes 风色环样式）
- 位于颜色面板底部，分隔线下方
- 点击 → 打开系统原生 `<input type="color">` 选色器，选完即生效，面板保持打开
- 本次不做不透明度滑块（InkEngine 暂无 alpha 支持，留待后续）

**交互优化（对比现状）：**
- 现状：两步选色（主色→色阶），点色阶立即关闭面板
- 优化：一步选色（18 色直接点击），面板持续打开，可反复切换比较，点外部才关闭
- 现状：自定义颜色行有冗余「应用」按钮
- 优化：移除「应用」按钮，系统色选器选完即生效（与原生 picker 行为一致）

### 2. 粗细面板（GoodNotes 风格）

**布局（从顶到底）：**
- 标题行：「线条粗细」左侧 + 数值（如 "3.0 pt"，tabular-nums，右侧）
- 大滑块：轨道 8px 高，圆角 4px；thumb 24px 白色圆形，带阴影；激活填充渐变色（interactive-accent 主色渐变）
- 分隔线
- 预设按钮行：5 个圆形按钮（1/3/5/8/12），每个按钮内有粗细预览线 + 数字标签，选中态为 accent 边框 + 浅背景

**预设按钮：**
- 5 个圆形按钮（44px × 44px），数值：1、3、5、8、12（pt 单位，GoodNotes 风格）
- 每个按钮内：顶部粗细预览线（高度 = 对应数值，居中），底部数字标签（10px）
- 选中态：accent 色边框 + 12% accent 色浅色背景 + 预览线变 accent 色
- 点击预设 → 立即应用粗细 + 滑块 thumb 位置同步

**手势修复（核心 bug fix）：**

- **根因**：粗细面板的水平滑块使用原生 `<input type="range">`，无 `touch-action` 限制。在屏幕边缘拖动时，浏览器/S Obsidian 会把水平滑动识别为「拉出侧边栏」手势，两者竞争，系统手势常胜出。
- **修复**：给 `.mobile-ink-swatch-panel`（所有弹出面板）加 `touch-action: pan-y`。含义：只允许垂直滚动手势穿透到父级/页面，水平方向手势由面板内元素消费，不再触发系统级侧边栏滑动。
- **额外加固**：粗细滑块容器再加 `touch-action: none`（完全消费所有手势），确保拖动 thumb 时绝不会泄漏。
- **颜色面板同理**：整体加 `touch-action: pan-y`，防止色点横滚或面板内其他水平手势与系统冲突。

**交互：**
- 拖动滑块 → 实时改变粗细，预览线同步变化
- 点击预设按钮 → 直接跳转粗细 + 滑块 thumb 移动
- 面板保持打开，点外部关闭

### 3. 工具栏按钮选中/按下态

**现有问题：** 原生覆盖层（`.mobile-ink-native-overlay`）作用域下，`.mobile-ink-active`、`:hover`、`:active` 样式均缺失，选中的工具无视觉反馈，按下也没有动效。

**修复细节**（从 `.mobile-ink-root` 作用域复刻到 `.mobile-ink-native-overlay` 作用域）：

| 状态 | 效果 | 覆盖元素 |
|---|---|---|
| `:hover` | 背景加深 → `--background-modifier-hover`，图标变亮 → `--text-normal` | 所有 icon button |
| `.mobile-ink-active`（通用） | 填充 accent 色背景 + 白色图标 + 柔和外阴影 | 非工具类按钮（撤销、重做、锁定等） |
| `.mobile-ink-tool-button.mobile-ink-active`（工具类） | 背景 = 14% 当前墨水色 + 底色；图标色 = 当前墨水色；底部 2px 指示条（::after，14px 宽） | 画笔 / 记号笔 / 橡皮擦 |
| `:active` | `transform: scale(0.94)`（按下缩放，移动端触感反馈） | 所有按钮 + 色点 + 预设按钮 |
| `:disabled` | 透明度 → 0.4，禁用点击感 | 条件禁用按钮 |
| 暗色模式变体 | 背景色/阴影/边框对应暗色变量 | 同上 |

**面板打开态高亮：**
- 打开颜色面板时，给工具栏上的颜色按钮（`.mobile-ink-current-color-button`）加上 `.is-active` class（底部指示条 + 背景高亮）
- 打开粗细面板时，给工具栏上的粗细按钮加上 `.is-active` class
- 关闭面板时移除对应 class
- 实现方式：在 `openColorSwatch` / `openWidthSwatch` 里给按钮加 class，在 `closeSwatch` 里移除。

### 4. 代码改动范围

- `src/overlay/shared/OverlayToolbar.ts`
  - `openColorSwatch()` 重写：18 色网格 + 取色器
  - `openWidthSwatch()` 重写：大滑块 + 预设圆形按钮
  - 面板打开/关闭时给颜色按钮/粗细按钮切换 `is-active` class
- `src/overlay/shared/OverlayToolkit.ts` — 暂不改（不加不透明度）
- `styles.css` — GoodNotes 风格面板全套样式 + 原生覆盖层按钮状态补全 + 手势 `touch-action`

### 边界与细节

- 面板定位逻辑（`positionSwatch`）保持不变
- 点外部关闭逻辑（`registerSwatchOutsideClose`）保持不变
- 颜色数据从「7 主色 × 5 色阶」改为 18 色扁平数组，`COLOR_SHADES` 保留供其他地方使用
- 不透明度：本次不加（InkEngine 暂无全局 alpha 支持，改造成本较高，留待后续）
- 预设粗细值从 [2,3,5,8] 扩展为 [1,3,5,8,12]（5 个预设，GoodNotes 风）
