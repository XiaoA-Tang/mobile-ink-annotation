# Mobile Ink Annotation

一款专为移动端设计的 Obsidian 手写批注插件。该插件允许你使用 Apple Pencil 或触控笔，直接在你的 Markdown 笔记和 PDF 文件上进行手写绘图与批注。



## 🌟 功能特性 (基础版)



基础版提供了你在 Obsidian 中进行手写和批注所需的所有核心工具：



- **Markdown 批注**：直接在你的 Markdown 笔记上绘图和书写。

- **PDF 批注**：无缝手写批注 PDF 文档。

- **核心绘图工具**： 

&#x20; - 画笔与荧光笔

&#x20; - 橡皮擦

- **自定义设置**： 

&#x20; - 选择自定义笔迹颜色。

&#x20; - 调整笔迹宽度/粗细。

- **操作**：撤销、重做、保存和退出。



*(注意：独立手写笔记、嵌入预览、笔迹选择、图像捕捉、PDF 文本批注以及触摸输入等高级功能仅限专业版（Pro Edition）提供)。*



## 📥 安装指南



### 选项 1：社区插件市场（推荐）

*当插件在官方目录中审核通过后：*

1. 打开 Obsidian **设置 (Settings)** -> **第三方插件 (Community Plugins)**。

2. 关闭安全模式 (Safe Mode)。

3. 点击 **浏览 (Browse)** 并搜索 **"Mobile Ink Annotation"**。

4. 点击 **安装 (Install)**，然后 **启用 (Enable)** 插件。



### 选项 2：手动安装

1. 从 [Releases](https://github.com/jepicaju862-lab/mobile-ink-annotation/releases)页面下载最新版本的 `.zip` 文件。

2. 解压该文件夹并将其放置在你的笔记库 (vault) 插件目录中：`<vault>/.obsidian/plugins/mobile-ink-annotation/`。

3. 重新加载 Obsidian。

4. 前往 **设置** -> **第三方插件** 并启用该插件。



## 🖊️ 使用方法

1. 打开任意 Markdown 笔记或 PDF 文件。

2. 触发批注模式（例如，通过侧边栏图标或命令面板）。

3. 使用你的触控笔或 Apple Pencil 开始绘图。

4. 点击 **保存** 图标将你的手写内容提交到文档中。
