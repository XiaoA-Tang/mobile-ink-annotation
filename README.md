# Mobile Ink Annotation
A mobile-first handwritten annotation plugin for Obsidian. This plugin allows you to draw and annotate directly over your Markdown notes and PDF files using your Apple Pencil or stylus.

## 🌟 Features (Basic Edition)

The Basic Edition provides all the essential tools you need for handwriting and annotating in Obsidian:

- **Markdown Annotation**: Draw and write directly on top of your Markdown notes.
- **PDF Annotation**: Handwrite on your PDF documents seamlessly.
- **Core Drawing Tools**: 
  - Pen & Highlighter
  - Eraser
- **Customization**: 
  - Select custom stroke colors.
  - Adjust stroke width/thickness.
- **Actions**: Undo, Redo, Save, and Exit.

*(Note: Advanced features like standalone ink notes, embed previews, stroke selection, image capturing, PDF text annotation, and touch input are exclusive to the Pro Edition).*

## 📥 Installation

### Option 1: Community Plugins (Recommended)
*Once the plugin is approved in the official directory:*
1. Open Obsidian **Settings** -> **Community Plugins**.
2. Turn off Safe Mode.
3. Click **Browse** and search for **"Mobile Ink Annotation Basic"**.
4. Click **Install**, then **Enable** the plugin.

### Option 2: Manual Installation
1. Download the latest release `.zip` file from the [Releases](https://github.com/YOUR_GITHUB_USERNAME/mobile-ink-annotation-basic/releases) page.
2. Extract the folder and place it in your vault's plugin folder: `<vault>/.obsidian/plugins/mobile-ink-annotation-basic/`.
3. Reload Obsidian.
4. Go to **Settings** -> **Community Plugins** and enable the plugin.

## 🖊️ Usage
1. Open any Markdown note or PDF file.
2. Trigger the annotation mode (e.g., via the ribbon icon or command palette).
3. Use your stylus or Apple Pencil to start drawing.
4. Click the **Save** icon to commit your handwriting into the document.
